# EthernetModule
This is a custom Ethernet module for the hackxpansion console made by @koeg. It has been created with some simple components. It was made for the purpose of having internet on the hackxpansion console via wire, or even to have local multiplayer.

## Design
This module has been designed with the following requirements and components
single slot hackxpansion module
W5500 PHY ic communicating over spi
Ethernet port with integrated magnetics
length and impedance matched
up to 100Mb/s speed
